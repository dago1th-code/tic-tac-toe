# David Harris Tic Tac Toe Game

A modern Tic Tac Toe game built with React and TypeScript, featuring player names, score tracking, sound effects, difficulty levels, and a computer opponent.

## Technologies Used
- React
- TypeScript
- Vite
- CSS Modules

## How to Run
1. Clone this repository
2. Run npm install
3. Run npm run dev
4. Open the local link shown in your terminal

## Main Features
- Player names and score tracking
- Reset and new game controls
- Winner celebration and draw detection
- Sound effects and difficulty levels
- Computer opponent

## New Features Added
- Match history and analytics panel
- Dark/light theme toggle
- Rounded corners and shadow styling on header
- Improved UI/UX design
